## 🧠 Project Overview

This project presents a comprehensive **equity investment thesis on TSMC (NYSE: TSM)**, structured in the format of institutional buy-side research.

It combines:
- Strategic analysis
- Financial modeling (DCF, scenarios)
- Competitive positioning
- Market structure insights

All delivered through a **high-performance interactive web interface**.

## 🎯 Investment Thesis

TSMC represents the **core infrastructure layer of the AI revolution**.

Key idea:
> Every advanced AI chip globally is manufactured by TSMC.

### Core Drivers:
- Monopoly-like position in leading-edge semiconductor nodes (3nm → 2nm)
- Explosive demand from AI / HPC (Nvidia, Apple, AMD)
- Structural pricing power → margin expansion
- Geopolitical risk mitigation via Arizona fabs
